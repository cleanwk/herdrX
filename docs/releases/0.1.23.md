# HerdrX 0.1.23

- Drag tabs to reorder them again. In 0.1.22 pressing a tab in the title bar area could move the whole window instead of the tab. The window no longer moves while the pointer is over the tab strip; the rest of the title bar still drags the window.

Validation: [tab interaction](../tab-interaction/VALIDATION.md). Native CI now drags a tab with real HID mouse events, both in a SwiftUI window with a hidden title bar and in the built app against a real Herdr server, and checks the new order. Physical mouse and trackpad acceptance was not run in CI.
