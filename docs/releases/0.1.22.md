# HerdrX 0.1.22

- Close panes immediately: the local terminal attachment stops and surviving panes expand from the current layout before Herdr confirms. A deliberate close no longer flashes `terminal … not found` or a reconnect overlay. If the close fails, the pane is restored and the error is shown.
- Drag tabs across the full strip. Tab reorder keeps the mouse gesture even when the window can be dragged by its background, and a background refresh no longer cancels an in-progress drag.
- Doubao and other input methods finish composition cleanly: while text is marked, the terminal reports the input method's own caret; asynchronous commits clear the marked text first and fall back to native input if the terminal binding refuses. Asynchronous dictation commits are written once, as text, without paste framing.
- The tab strip redraws only when a tab's colour actually changes.

Validation: [terminal input](../terminal-input/VALIDATION.md), [tab interaction](../tab-interaction/VALIDATION.md), [scoped snapshots](../connection-recovery/scoped-snapshots.md). Native CI covers selection/IME, tab drag, pane action, PTY and input harnesses. Physical Doubao hold-to-talk and trackpad acceptance were not run in CI.

## 中文

- 关闭面板即时生效：确认后立即停止本地终端连接，剩余面板按当前布局扩展，不再等待服务端返回；主动关闭不再闪现 `terminal … not found` 或重连提示。关闭失败时恢复面板并显示错误。
- 标签可以沿整条标签栏拖动排序。即使窗口支持拖动背景，拖拽手势也不会被窗口抢走；后台刷新不会打断正在进行的拖拽。
- 豆包等输入法的组字可以干净结束：组字期间向输入法报告它自己的光标位置；异步上屏前先清除组字状态，终端绑定拒绝时回退到原生输入。异步语音输入以普通文本写入一次，不按粘贴包裹。
- 标签栏只在颜色确实变化时重绘。
