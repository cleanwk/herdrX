# HerdrX 0.1.20

- Fix new terminal tabs appearing unresponsive when a background refresh overtakes the completed create request. Publish completed snapshots in order before selecting the created tab.
- Fix delayed rename and split results in large sessions. Coalesce reads that have not started and read independent workspace/Agent scopes with at most four concurrent sockets.
- Preserve post-mutation freshness, connection identity, server ordering, complete topology validation and the last usable snapshot on failure. Cancelling one refresh waiter does not cancel other callers.

Validation: [scoped reads and action latency](../connection-recovery/scoped-snapshots.md). The current PR head must pass the complete macOS workflow before release. Synthetic latency tests do not establish timing on the user's Mac; installation and Apple notarization remain separate outcomes.
