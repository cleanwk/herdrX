# HerdrX 0.1.24

- Filter sidebar Spaces and Agents by All Activity, Working or Needs Attention. The current task remains visible; an empty result offers Show All Activity.
- Create terminal tabs from the button beside a Space or its context menu. New Space is explicitly labeled, and asynchronous creation keeps the captured target and restores usable state on failure.
- Show useful Agent task titles instead of automatic numeric Tab labels. Group confirmed equivalent device connections in navigation while retaining saved configurations and the selected terminal identity.
- Overlap the two read-only scroll preflight queries and include wheel samples queued during the wait in the same batch. Foreground process verification and server-owned history remain mandatory.
- Reuse exported split layouts across metadata changes and return navigation. Refresh after topology, geometry, transport, explicit ratio changes or an optimistic pane close; a rejected close restores the authoritative split tree.

Validation: [Rex comparison and implementation](../rex-beta-comparison/VALIDATION.md). Controlled reads of 250ms each complete their parallel preflight in about 251ms; this excludes the scroll write, transport of terminal output and drawing. Slow remote control channels are not fixed by this release. Navigation grouping does not pool existing SSH connections. Apple notarization remains a separate release outcome.
