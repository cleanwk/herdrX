# HerdrX 0.1.19

- Fix Doubao voice input remaining underlined instead of committing in terminal panes. The AppKit host now keeps a stable insertion range throughout composition, while Ghostty continues to own marked text and final input delivery.
- Fix dragging a tab moving the window instead of reordering tabs. Drag horizontally to reorder; the tab context menu now contains only Rename and Close.
- Recover from truncated large Herdr 0.9.3 snapshots using smaller workspace, tab, pane, layout and agent reads. Remember the fallback across reconnects, check topology before publishing, and preserve the last complete cache if a read fails.
- Add native regressions using the production TerminalView and a real Ghostty in-memory session, covering composition, cancellation, UTF-16 marked ranges and asynchronous UTF-8 delivery. Tab regressions dispatch through the native window with background dragging enabled.

libghostty-spm remains pinned at 1.6.20260909. Existing shortcuts, preedit rendering, candidate positioning and surface lifecycle are unchanged.

Validation: [terminal input](../terminal-input/VALIDATION.md), [tab interaction](../tab-interaction/VALIDATION.md) and [large session recovery](../connection-recovery/scoped-snapshots.md). Release requires all checks for the current PR head to pass. Native integration tests do not replace physical Doubao/microphone acceptance on the user's Mac; installation and Apple notarization are separate outcomes.
