# HerdrX 0.1.17

- Fix misleading “Directory unavailable” warnings when a remote environment cannot run Git. Optional branch lookup now falls back to the ordinary folder/Directory row.
- Keep the last known branch visible when a refresh fails, without an inline stale warning. Hover details retain a localized explanation and the underlying diagnostic.
- Preserve normal branch refresh, server-provided branch metadata and device connection status.

Validation and scope: [sidebar metadata](../sidebar-metadata/VALIDATION.md). Apple notarization and installation are separate from release packaging; this change does not install Git or modify remote sessions.
