# HerdrX 0.1.6

本版聚焦 Space、Tab、Pane、真实终端、连接、Agent 状态与搜索。

- 移除专用 Agent 启动器、命令覆盖、文件树、预览、双端文件传输及附件投递。请在终端直接运行 Agent CLI；自动识别、状态导航与普通文本复制粘贴继续保留。
- 统一任务标题与设备上下文，改进 Agent 行层级、离线说明和分支状态。
- 修复搜索方向键、稳定选择、标签自动滚入可视区与关闭后的相邻选择；明确服务器关闭影响与本机忙任务确认。
- 创建和插件操作保留原目标，减少异步导航与焦点干扰；隐藏应用保留终端连接。
- 设置收敛为外观、终端、连接、关于与更新；改善连接草稿重置、可访问性与状态文字对比度。

原生技术栈、紫色斜杠图标、设备身份、Keychain 和更新渠道保持不变。旧功能偏好停止读取，不删除用户文件。

## 安装与升级

```sh
brew update && brew upgrade --cask herdrx
```

安装包由 GitHub Actions 生成，包含 Apple Silicon 与 Intel 架构。沿用当前 ad-hoc 签名方式，不宣称 Apple 公证。首次打开可能需要在系统设置的隐私与安全中确认。

本轮完成 19 项核心测试、PTY 代次与前台任务判定、4 项发布契约测试及 universal Release 构建。原生操作、截图、400 条合成 Agent 元数据性能采样及 24 个服务器 surface 复用记录见[实现与验收](../ux-audit/RESULTS.md)。

真实 IME、VoiceOver、SSH/Tailcat 远端、Intel 实机及完整主题矩阵等尚未全部验收；[C01–C90](../ux-audit/ACCEPTANCE.md)保留逐项证据和限制。
