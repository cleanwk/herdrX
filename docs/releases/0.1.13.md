# HerdrX 0.1.13

- Terminal selection copies once on release when Copy on Select is enabled, clears the copied selection and shows a brief confirmation. Consecutive selections start at the new anchor.
- Captured clicks are deferred until release; dragging selects locally without clicking the TUI. Holding at the upper/lower edge extends through available terminal history. Hiding or unfocusing a pane cancels the gesture.
- Refined Catppuccin surfaces and normal/selected text hierarchy. Accent borders retain the chosen color; working and unread states use stable blue, while idle stays neutral.
- Preserve terminal ANSI palette semantics for background and reverse use, restore a distinct faint style, and clarify that Local Herdr theme follows only the local theme family.
- Includes the preceding native layout, menu and editing refinements.

Validation and remaining native acceptance: [selection/theme record](../selection-theme/VALIDATION.md). Signed Sparkle updates and universal Apple Silicon/Intel packaging use the existing release workflow. Apple notarization and installation are reported from release metadata, not implied by publication.
