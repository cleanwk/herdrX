# HerdrX 0.1.7

本版按 ACCM 参考调整原生工作台的布局、字体和颜色，并将导航收敛为 Space 与 Agent。

- 校准侧栏宽度、行高、字号、文字对齐、标签栏和面板间距，改进紧凑窗口布局。
- 提供 Catppuccin、Tokyo Night、Gruvbox、One、Solarized、Kanagawa、Rosé Pine、Dracula、Nord、Vesper 十个配色主题族，以及默认和跟随 Herdr。系统 / 浅色 / 深色与强调色独立切换，工作台和终端同步更新。
- 使用原生图标工具栏设置页，调整外观与终端字段排版，增加双行设备切换菜单。
- 修复带分隔线的原生配色菜单在更新时重建的问题，完善中文文案和状态对比度。
- 移除独立本机 Shell、终端列表及相应创建入口；保留 Space 内的会话、Agent 输出、标签、分屏和输入操作。

已有偏好继续保留；恢复终端默认值时优先选择可用的 Maple Mono CN，否则使用 SF Mono，字号为 13.5 pt。Dracula 与 Vesper 的浅色变体是 HerdrX 的配套设计。

## 安装与升级

```sh
brew update && brew upgrade --cask herdrx
```

正式安装包由 GitHub Actions 构建，包含 Apple Silicon 与 Intel 架构。沿用 ad-hoc 签名，不宣称 Apple 公证。

## 验证范围

20 项核心测试、4 项发布契约测试、PTY 前台任务判定与 20 次重启/输出/输入验证通过。原生界面完成全部配色菜单选择、Space 内标签与分屏操作，以及浅色、深色和紧凑窗口检查。Universal Release 构建与签名完整性验证通过。

完整记录见[原生验证](../accm-fidelity/evidence/native-checks.json)和[复核裁定](../accm-fidelity/VERDICT.md)。配色逐项视觉审计、VoiceOver、IME、低版本 macOS、Intel 实机、Tailcat 和系统通知权限尚未全部验证。
