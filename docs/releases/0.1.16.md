# HerdrX 0.1.16

- Fix stale keyboard protocol sequences appearing immediately after opening a terminal. Physical Ctrl-C now sends an interrupt even when a pane retains Kitty keyboard modes; recovery preserves running terminal apps and server sessions.
- Fix terminals shifted to the right or clipped when connecting to older Herdr servers whose layout area has a sidebar/header offset, including Herdr 0.8.2.
- Follow the local Herdr machine directory on startup, app activation and every 60 seconds. Add new managed devices, update changed labels/targets/sessions and remove missing or disabled managed devices. Manual devices are preserved, and failed catalog reads never delete devices. The behavior can be disabled in Connections settings.
- Import remote machines without waiting for SSH. Resolve named-session sockets when connecting, retry unavailable machines independently and start stopped remote named sessions through Herdr's supported bridge.
- Show local Herdr `ui.tab_bar_right` command output in the sidebar footer. Expose `keys.command` popup commands in ⌘K and the Herdr Commands menu, using floating terminals that close when their process exits.
- Expose enabled plugin actions and panes in ⌘K and the Plugins menu across connected devices. Plugin panes can open in floating windows.
- Add signed incremental in-app updates from up to three preceding stable releases. Sparkle falls back to the full archive when no suitable delta is available or a patch fails; initial installs and Homebrew upgrades continue to use the full archive.

Validation: [terminal input](../terminal-input/VALIDATION.md), [machine/config/plugin integration](../herdr-integration/VALIDATION.md), [legacy/current Herdr layout compatibility](../pane-spacing/layout-origin.md) and [signed delta updates](../app-updates/VALIDATION.md). Implementation checks passed on macOS, including 63 Core tests, 13 native tests, 14 Python release checks, real Herdr fixtures and universal packaging. The user's physical MacBook Air and live ACC environment still require verification after installation; the reproduced layout defect does not establish a hardware-specific cause.
