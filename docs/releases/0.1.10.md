# HerdrX 0.1.10

- Fix tabs moving vertically or becoming clipped. The 28pt bar keeps 22pt tabs centered and constrains overflow to the horizontal axis, including selection and window resizing.
- Show concise connection states with a clear recovery action. Guidance and technical details move into an info popover; empty states are centered.
- Start a stopped local Herdr session through its existing CLI. Readiness checks, duplicate-start protection and failure recovery keep the UI responsive. Custom socket paths open connection settings instead of guessing which server to launch.
- Rewrite README in concise English, covering installation, setup, shortcuts and development.

Herdr remains responsible for sessions and processes. Quitting HerdrX leaves them running. Update through Check for Updates or `brew upgrade --cask herdrx`.

Validation includes 28 Core tests, native tab regression tests, PTY checks, packaging tests and isolated native UI checks. See [validation and limits](../connection-recovery/VALIDATION.md). Universal Apple Silicon/Intel packaging and signed Sparkle updates use the existing release workflow; Apple notarization is unchanged.
