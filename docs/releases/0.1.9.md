# HerdrX 0.1.9

优化终端工作台的标签、分屏操作和 Agent 辨识度，继续复用 Herdr 的会话、布局及命名能力。

- 顶栏统一为 28pt，标签高 22pt，上下各留 3pt、标签间距 4pt；激活和未激活标签使用不同层级的浅底色。
- 聚焦 Pane 保留低透明度关闭按钮，提供 22×22pt 点击区域和 150ms 渐隐；标题栏右键菜单与 ⌘⇧W 继续调用 Herdr 原有关闭流程。
- 窗口外侧底角使用连续曲线，内部分屏保持直角和对齐的细线。
- Claude、Codex、Gemini、DeepSeek、Kimi、Antigravity 显示品牌配色；上游只提供单色的品牌保留官方单色图标。修正 macOS SVG 解析压缩弧线时显示不完整的问题。
- 双击标签、右键菜单或 Terminal → Rename Tab…（⌘⌥R）打开重命名面板；支持中文、空格和符号，禁用空白及未修改名称。提交串行调用现有 tab.rename RPC，失败保留原名和输入，允许重试。
- 包含此前合并的侧栏原生滚动条、设置布局及导航性能优化。

可通过应用内“检查更新”或 `brew upgrade --cask herdrx` 升级。安装包支持 Apple Silicon 与 Intel，最低 macOS 14；沿用 Sparkle 签名更新验证。

本地验证包含 22 项 Core 测试、Debug 构建、隔离客户端重命名成功/失败恢复和原生图标渲染检查；通用构建、PTY 和打包由 PR/发布 CI 验证。完整检查范围及未实测的 VoiceOver、深色/全屏等场景见[验收记录](../ui-five/VALIDATION.md)。
