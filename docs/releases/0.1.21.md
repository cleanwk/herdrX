# HerdrX 0.1.21

- Remove the full-session refresh from the critical path after splitting, closing, creating a tab and renaming. Read and validate only the affected Space, then update the native UI; unrelated Space and Agent metadata refresh in the background.
- Remove closed native terminal surfaces and expand surviving panes using server-provided geometry. Keep surviving terminal objects mounted.
- Share read-start revisions between scoped and full reads so a late full snapshot cannot resurrect a closed pane or remove a new split. Preserve connection/transport checks and fall back without repeating a mutation when a scoped read fails.

Validation and measured latency: [action latency](../connection-recovery/action-latency.md). Native tests deliberately delay full snapshots by two seconds; this is an isolated fixture, not a timing claim for every live session.

## 中文

- 分屏、关闭面板、新建标签和重命名后，先读取当前 Space 并更新界面，不再等待整个会话和全部 Agent 刷新。
- 关闭后移除原生终端视图，按服务端布局扩大剩余面板，保留剩余终端对象。
- 防止晚返回的全量快照覆盖新布局；局部读取失败时保留可用界面并回退，不重复执行关闭或分屏。
