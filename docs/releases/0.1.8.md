# HerdrX 0.1.8

修正主题文字层级与浅色模式可读性，并加入签名验证的应用内更新。

- 导航、正文、次要文字、选中状态与强调色分别处理，修正 Tokyo Night 浅色模式整页泛蓝。
- 修正 Gruvbox Light 和 Rosé Pine Dawn 的 ANSI 黑色，使浅色差异块中的文字可读；保留十套主题、深浅模式与独立强调色。
- 自动检查默认开启，每 24 小时检查一次；自动下载默认关闭，开启后可在退出应用时安装。
- HerdrX 菜单和设置 → 关于提供手动更新、上次检查时间、取消和失败状态。
- GitHub CI 生成并验证签名更新清单和安装包；Homebrew 与直接下载的安装使用同一更新器。

v0.1.7 用户需先通过 `brew upgrade --cask herdrx` 或下载本版本完成一次升级，后续可使用应用内更新。安装包支持 Apple Silicon 与 Intel，最低 macOS 14。更新签名使用 Sparkle Ed25519；当前仍为 ad-hoc 应用签名，未进行 Apple 公证。

验证包括 20 项 Core 测试、6 项发布测试、十套主题的深浅模式截图，以及隔离环境中的手动安装、自动下载/退出安装、取消、已是最新版本和无效签名拒绝。详见[主题验证](../theme-correction/VALIDATION.md)和[更新验证](../app-updates/VALIDATION.md)。
