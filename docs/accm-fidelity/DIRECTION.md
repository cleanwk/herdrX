# ACCM 对照改版

2026-10-10。用户提供的五张 ACCM 截图是本轮视觉依据，取代 0.1.6 的中性灰白界面方向。用户明确确认：删除独立本机 Shell、终端列表和创建入口；保留 Space 内普通会话、Agent、标签与分屏操作。主题必须可切换，不能固定成截图中的一个主题。

Mode: Operate。使用原生 SwiftUI / AppKit / Ghostty，实现截图中的紧凑工作区。品牌、图标和设备连接模型保持现有产品身份。

## 尺寸与排版基准

参考工作区原图为 3840×2100，按 2× Retina 阅读；设置截图同样按 2× 阅读。比较原始图片的原生 point 尺寸，不能把查看器缩至 2048px 的预览当作 1× 原图。

- 工作区侧栏默认 260pt，顶部栏 28pt，操作区与底栏各 40pt；Space / Agent 正文 13pt，元数据 11pt，分组 11pt semibold。保留用户保存的侧栏宽度。
- Space 与 Agent 文字起点统一约 36pt；Space 条目约 45pt、Agent 51pt，两行条目与尾部状态对齐。分组连接圆点紧跟设备名。第一排面板顶框距窗口顶部约 42pt。
- Catppuccin 默认浅色 `#eff1f5` / `#4c4f69`；选中态蓝色，Space 轻填充带轮廓，当前 Agent 填充更明显；完成状态绿色，等待输入琥珀色，未知状态单独标示。
- 原生设置采用顶部图标分页。外观宽 420pt，正文高 190pt；终端正文高 410pt。连接与 Tailcat 使用较宽的 600pt 编辑区。原生控件保留系统键盘、菜单和可访问性行为。
- 外观表单的控件起点约 83pt；主题三段选择、配色原生菜单、九个强调色圆点、语言菜单。终端表单统一字段起点、显示 pt / 百分比，底部提供真实选中字体的预览。
- 设备弹出列表显示两行名称 / 连接来源、在线 / 离线圆点、当前勾选与添加设备入口。

## 主题与范围

主题族：Catppuccin、Tokyo Night、Gruvbox、One、Solarized、Kanagawa、Rosé Pine、Dracula、Nord、Vesper；另有 HerdrX 默认与跟随 Herdr。系统 / 浅色 / 深色独立于主题族。强调色可独立选择或跟随主题。

主题数据来自当前依赖中的 GhosttyTheme 预设；Dracula / Vesper 没有上游浅色预设，使用明确命名的 HerdrX 浅色配套，而非宣称它们是上游官方浅色。跟随 Herdr 解析本机 `[theme].name`，不修改 Herdr 配置。

不添加 ACC、专用 Agent 启动器、文件树、预览或传输。终端设置保留，因为 Space 内仍使用真实终端引擎。主题更换应保留会话与历史。

使用隔离的 `herdrx-fidelity-20261010` 会话和 Debug 应用；用户已有会话不是测试数据。Agent 状态和屏幕文字为明确标识的合成内容，PTY / attach / split 真实运行。原生截图覆盖工作区浅深色、紧凑窗口、设备弹出列表和设置页。尚未执行的环境或功能不记为通过。

质量基准：输入与选择行为可靠；参考中的文字尺寸、基线和控件层级可解释；主题切换有真实效果；长标题不挤掉状态；没有独立 Shell 入口。主构建线程完成两轮检查后交给独立 finish reviewer；原生 macOS 不运行 Web HTML/CSS detector。
