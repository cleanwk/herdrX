## ceiling

The gap is readable color hierarchy, not additional expression. The reference allows task names to recede while current focus and Agent state remain legible. Palette selection alone did not validate that hierarchy. Neither wholesale desaturation of terminal output nor resetting the user's palette to Catppuccin would fulfill the switchable-theme contract. Ghostty's renderer exposes a native minimum-contrast control; use that capability for terminal readability rather than rewriting arbitrary application output bytes.
