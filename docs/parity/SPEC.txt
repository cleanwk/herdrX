ACCM → HerdrX 功能、页面与交互复刻说明（自包含版）
本文可整篇复制给 HerdrX 开发者或其 Codex。正文包含功能对比、页面规格、实施任务、验收清单、启动指令和匿名测试数据，不依赖图片、附件或本次聊天。源码路径与公开网址仅供追溯，不是理解和实施本文的前置依赖。
结论：HerdrX 已有可用的终端与 Herdr 会话基础，主要差距是工作台的信息组织、操作上下文、状态反馈、设置完整度和文件辅助能力。应在现有 HerdrX 架构上分阶段补齐，不需要重新开发运行时。
目标是复刻 ACCM 的通用功能与页面交互，保留 HerdrX 品牌；排除 ACC 业务集成。本文给出可独立实施的规格，不以开发者能访问 ACCM 内网仓库为前提。

1.1 范围解释
保留：本机/SSH/Tailcat 设备、Space/Tab/Pane、Agent、独立 Shell、终端交互、搜索、注意力、通知、主题、语言、文件、设备管理及通用系统集成。
排除：ACC 账号关注、机器订阅、SIM 发现/创建、Code Studio 接入、ACC CLI 安装与自动同步、ACCKit 业务 DTO、ACC 专属设置/菜单/快捷键、ACC 内网更新渠道。无需建设旧蓝图中另拟的宿主插件 SDK。
Herdr 原生插件仍保留。 HerdrX 现有 plugin.* 功能不等于 ACC 插件；不要误删 Settings → Plugins、动作、日志、终端插件面板。运行时上报的模型/账号/额度信息也不天然属于 ACC；仅在真实有数据时呈现。
HerdrX 当前 PRODUCT 明确不做文件浏览/预览/传输，这是此前产品取舍，并非意外缺陷。本次“除 ACC 外复刻”的目标将它们纳入；开发者实施时应同步修订该产品范围。Tailcat、文件和完整设置都不能因排期靠后而从“完整复刻”定义里消失。
2. 为什么 ACCM 的交互更完整
2.1 主窗口减少重复结构
HerdrX Workbench 是 48pt 工具栏 + 38pt 标签栏 + 26pt 底部状态栏，另有分隔线。ACCM 的详情区将 Tab 与窗口顶部整合，TitlebarMetrics.height = 28pt，Pane 标题嵌入细边框。按这些组件名义高度计算，常驻横条为 112pt 对 28pt；这是结构预算差，不是实测净可用高度差，还需考虑系统安全区与 Pane 内边距。
HerdrX 把 Jump/New Agent/加号/分屏/设置都放在顶部，设备过滤又在侧栏上部，设备名在多个位置重复。ACCM 将定位操作固定在左侧，空间标签在上方，设备/设置在左下；用户更容易记住操作位置。

2.2 好处来自状态语义，不只是颜色
	▪	Space 第二行使用分支或安静的“目录”，完整路径放辅助信息，避免每一行都被长路径占据。
	▪	Agent 有独立选中背景、工具图标、所属 Space、状态文字；工作中、等待输入、完成未读有不同图形。
	▪	Space 汇总其内部 Agent 的注意力，用户不展开所有内容也知道哪里需要处理。
	▪	跨 Space Agent 汇总与当前项目导航同时存在，点击 Agent 直接定位对应 Space/Tab/Pane。
	▪	当前 HerdrX 已跨 Space 汇总，但 Agent 行只有简化状态点，没有 ACCM 同级的选中/未读表达；排序也不同，不能把“已有列表”当成体验等价。
2.3 高频操作有捷径，低频能力按需展开
ACCM 快速新 Space 继承当前目录，成功后进入默认 Pane；HerdrX 必须经过设备/名称/绝对目录表单。ACCM 文件区默认隐藏，需要时在现有终端旁展开；主题、鼠标、复制和字体控制集中在设置。熟练用户日常少走表单，复杂选项仍可发现。
2.4 HerdrX 应保留的基础
HerdrX 已有真实 Ghostty 终端、隐藏表面复用、设备作用域、分屏/拖动、拼音搜索、通知路由、SSH 退避重连、服务端 Pane 关闭确认及原生 Herdr 插件接口。它的首次启动可直接用本地 Shell，无需 Herdr。这些都是可继续使用的基础；复刻过程中不得退化。

4. 页面与控件规格
规格级别：以下标明“当前值”的尺寸来自 ACCM 源码；“目标约定”是为独立实现补全的约束。文字参数和行为定义构成该单文档版的实施基线。
S01 主工作台
当前最小窗口 980×620pt，侧栏初始 260pt，可在 200–480pt 拖动，分隔线 1pt、命中宽 7pt，双击恢复 260pt；宽度与折叠保存在 HerdrX 偏好空间。顶部高 28pt，左侧交通灯预留 78pt。窗口仍可拖动、双击缩放，全屏可用。
左侧：顶部新建菜单、快速新 Space、搜索；中间设备/Space、Agent、终端分组；底部 40pt 设备切换与设置，列表滚动不带走头尾。设备分组及 Agent/终端分组可折叠，分组标题吸顶；无多余空分组。侧栏隐藏后，顶栏仍可恢复侧栏。
右侧：顶栏显示当前 Space 的 Tabs、加号、分栏与文件菜单；下方直接为终端 Pane。无固定第二条设备标题栏、无默认常驻底部状态条。连接错误在相关设备/Pane 附近提示，不用整页错误遮蔽其他设备。
目标约定：保留 HerdrX 首启本地 Shell。无 Herdr 时可输入命令，设备列表展示明确连接状态及接入入口，不弹阻断式初始化向导。
S02 侧栏行与注意力
共同列：外 inset 10pt、行 inset 8pt、图标列 12pt、列间距 6pt，正文起点相对列表内容为 26pt。标题行高 28pt。行的点击区域覆盖整行；hover 为中性浅底，选中使用主题色浅底与细边，不能把 hover 画成第二个选中项。
Space 标题 13pt、当前项 medium，次行 11pt，垂直间距 3pt、上下 padding 6pt。两行结构常驻；分支查询未返回时保留不可见占位，查询成功无分支才显示文件夹和“目录”。右侧放聚合注意力图标。圆角 8pt。名称尾部截断，路径可 tooltip/复制，不用长路径替代分支行。
Agent 标题 13.5pt；次行 11pt，展示工具图标、工具名、所属 Space，多设备范围时增加设备上下文；状态文字靠右。上下 padding 7pt，选中圆角 7pt。可选附加行展示服务端确实提供的模型/账号/上下文/额度；无值不留空条、不猜数据。允许附加行增加高度，不强压为单行。
状态映射：working 用蓝色半实圆；blocked 用警示色实圆；done 未读用蓝色实圆；done 已读及 idle/unknown 用低强调空圆，并有对应可访问文字。unknown 不能显示为“完成”。设备色和连接状态色独立。
Space 聚合优先级为 blocked → unread done → working → none。Agent 列表排序则是 blocked → working → done → idle → unknown，同等级按设备、Space、Tab 顺序稳定排序；这两种规则不要混用。HerdrX 当前 rank() 是 blocked → done → working，应调整到目标规则。
Agent 列表范围为当前设备筛选下的所有 Space。选择 Space 不应隐藏其他 Space 的 Agent；普通终端列表可按所选 Space 缩小。点 Agent 时同时设置正确 device/space/tab/pane，保持侧栏选择和终端焦点一致。
S03 Tab、Pane 与对象菜单
Tab 顶栏占 28pt；标签随文字紧凑布局、长名截断，可水平滚动。目标约定：标签最小点击宽 40pt、常态文字宽加左右各10pt、最大200pt；此宽度约定用于独立实现，不冒称 ACCM 固定常量。选中标签使用主题色 wash+边界，hover 中性；tooltip 显示完整名称。
Tab 拖动按鼠标落点左右半边确定插入位置；显示插入线，立即更新本地顺序，串行发送服务端排序；跨设备/Space 拒绝。失败只回滚本次排序，不覆盖之后的选中项和后续成功操作。重命名、关闭和新建都可从菜单与快捷键执行。切回 Tab 恢复最后聚焦 Pane。
Pane 使用 1pt 轮廓；标题嵌在顶部线条内，而不是独立大标题栏。标题 11pt 等宽，聚焦时 semibold+accent；副标题 11pt 显示 Space/必要设备信息。内容顶部 padding 10pt、边缘1pt、外padding3pt；标题左右 padding9pt。关闭按钮20×20pt，hover或VoiceOver时可用；缩放显示恢复标记。macOS 26 窗口外侧下角可随窗口圆角，内部拆分边保持方角；旧系统回退矩形。
右键必须命中鼠标所在对象：Tab 菜单含重命名/关闭；Space 含重命名/关闭/复制目录；Pane 含复制/粘贴、可用链接、重命名、左右/上下分屏、缩放/恢复、移至新Tab、关闭。禁用项保留原因或上下文说明，无选区复制置灰。不能先选中A、右键B却关闭A。
分屏查询目标设备当前 Pane cwd，再创建；查询失败展示错误，不用本机 cwd 兜底远端。拖动比例在本地反馈，落下后提交服务端。Pane/Tab关闭确认说明会终止哪些服务端进程；断开客户端/移除设备与关闭服务器 Pane 是不同动作。
S04 新建与搜索
快速新 Space：点击侧栏按钮或 ⌘⇧N，使用当前设备、当前 Pane/Space cwd，名称可空交给 Herdr；过程中禁重复；成功选中返回 Space/root Pane，不额外开 Agent 选择器、不多造 Tab。失败保留原选择并提示。另保留“新建 Space…”高级表单，允许明确名称/目录。
新 Agent：设备、Space、目录上下文清晰；工具列表来自目标设备；加载/空/失败/未安装均有状态。参数按 argv 解析；切设备后旧请求结果不能覆盖新选项。启动成功定位新 Pane，失败保留表单输入。本机命令覆盖只影响本机，不能把本机二进制路径发送为远端可执行路径。
搜索 ⌘K：ACCM 当前宽440pt，输入区44pt，结果最多320pt高，行36pt，底部键盘说明28pt；最多50项。覆盖 Space、Agent、Herdr普通终端、独立Shell及名称/设备/目录/分支，支持中文全拼和首字母。名称前缀→词首→名称子串→上下文排序，同级再考虑类型/注意力/近期活动。结果显示类型图标、标题及归属，↑↓/Return/Esc/hover共用一个选中索引。无结果有说明；目标被删时安全提示，不能落到同名其他机器。
S05 设置与视觉主题
保留原生设置窗口；通用设置页可按 ACCM 420pt 宽起步，高度随内容适配，复杂设备管理不强套此宽度。目标栏目：外观、终端、Agent、通知、Tailcat、关于；HerdrX 的 Devices、Plugins、Updates 可保留独立页并与底部入口连接。不要出现 ACC 页或灰色占位。
外观分成四项：系统/浅色/深色；配色（默认、跟随Herdr、主题族）；强调色（跟随主题、石墨、绿、蓝、紫、琥珀、粉、红、橙）；语言（跟随系统、简体中文、English）。主题变化同时影响侧栏、Tab、Pane边框、选择、终端，不能只改外层背景。深色独有主题在浅色回退到明示的默认方案。

S06 按需文件区
入口为顶栏“分栏与文件”→“浏览文件”及⌘⇧E，默认完全收起；打开后终端旁出现可调宽文件区，关闭后归还空间，不换 terminal view 身份。
根目录为当前Pane cwd，缺失回退目标设备home；独立Shell当前参考从home开始。目录懒加载、可折叠、隐藏文件开关、刷新、完整路径；只读文本/图片预览。文件区宽度≥520pt时树固定210pt并与预览并排；更窄时点文件进入预览，顶部返回箭头回目录。工具栏36pt。目标初始宽度320pt，最小240pt，最大可用详情宽度的60%，均属新实现约定；不强迫主终端低于可用宽度。
文件预览最多2MiB（2×1024×1024字节），超限明确提示；目录、符号链接、非支持类型不当普通文本读取。UTF-8解码/图片解码失败展示不可预览原因。仅本机/SSH实现浏览和传输；Tailcat明确“不支持该连接方式的文件操作”。切根/切设备/关闭期间返回的过期请求丢弃；失败不渲染成成功空目录。
S07 文件管理、设备管理和其他页
文件管理 ⌘⇧F：本地与目标设备双端列表，设备选择、路径输入、返回/上级/刷新/隐藏文件、名称/大小/修改时间列；选单个普通文件后可上传/下载。进度、已传字节、取消、失败、完成明确；冲突有取消/替换/保留两份；传输目录不在本次范围。目标约定：取消不宣称完成，临时/部分文件按明确策略清理并测试，不静默覆盖已有目标。
设备入口：底部当前设备/所有设备选择器显示连接点；可进入设备管理、添加/编辑/移除SSH、本机命名会话发现、导入Herdr已保存机器。展示名称、端点/会话、连接状态与错误；失败可重试；移除说明“只忘记连接，不删除远端会话”。IP或名称不作为唯一身份，socket必须对应正确命名会话。发现失败保留已有条目；手动设备不能被导入/刷新覆盖删除。
Tailcat：设备连接方式与客户端公钥设置；令牌/密钥进入独立Keychain命名空间。重新生成密钥说明对已有host allowlist的影响并确认。源码可实现但未实测时写未验收，不展示虚假connected。
插件页：继续沿用 HerdrX 的原生运行时插件清单/启停/动作/日志/Open in Tab；仅对真实可用上下文启用动作，不另建JSON表单SDK。模型/账号/额度等扩展行使用有界可选字段，不渲染任意富内容、不强行依赖某第三方插件。
关于/更新：HerdrX名称、版本/build、项目与第三方声明；Brew安装保持Brew更新，直装仅在签名更新配置可用时启用Sparkle。不要复制ACCM品牌、内网URL或命名空间。
5. 状态与终端行为合同
5.1 身份与选择
Device → Space → Tab → Pane 是导航层级；Terminal是执行实体，paneID不等于terminalID。所有引用均带deviceID。同一物理机器的不同命名会话可成为不同端点；两个设备均有p1不能串线。
服务端拥有Space/Tab/Pane/Agent状态；客户端拥有选择、折叠、未读、主题、文件区和attach。保存配置不能把上次connected当成当前事实。控制RPC与终端字节流分开，PTY输出不进入整个Desk的可观察状态。
5.2 未读与注意力的精确规则
参考 AgentUnread：初次快照不创建未读；已有Agent从非done转done才置未读；离开done状态或对象删除即移除。当前正选中时发生done也先置未读，参考实现是在离开该行时清理已观看项。这与通知“正在看就不提醒”是两套状态，不能用通知开关控制未读。
⌘⇧J只在当前设备范围的blocked和未读done中导航，blocked优先，按稳定Space/Tab次序；排除纯working和已读done，无候选禁用。重复选择不触发远端重启。
5.3 连接与attach
每设备独立idle→connecting→connected或failed；断线保留最后快照并标旧。普通重连退避1–30秒；认证失败进入凭据/重试流程，不循环弹窗。同设备仅一个有效连接代次，旧请求不能写新配置。
RPC成功、attach成功、画面刷新、Agent工作分别表达。被另一个客户端接管后提供恢复入口，不能循环抢回。关闭客户端释放attach，不自动调用pane.close；独立Shell由本机客户端拥有，不能宣传和服务器Pane相同的持久性。
5.4 输入与呈现
	▪	Shell启动/退出Agent仍是同一个device+pane终端身份，保留历史和输入。
	▪	隐藏Tab保留surface、session、输出和原网格，暂停绘制；可见未聚焦Pane收到输出也刷新。
	▪	切到其他App不是断开attach。参考实现显式⌘H隐藏1.5秒后释放attach，恢复时重连；迁移时单独验证，不与切Tab混为一谈。
	▪	PTY重启使用generation隔离旧read/write/exit回调与fd；不阻塞主线程等待旧IO退出。
	▪	中文组字/候选框/提交、语音提交、粘贴与快捷键分流。鼠标捕获中单击交给TUI，拖选/多击/Shift仍可本地选字。
	▪	边缘拖选进入上下12pt区域持续滚动延伸选区；松手、隐藏、窗口变化停止。使用终端选择滚动机制，不能向TUI伪造滚轮命令。
	▪	⌘单击链接支持折行/OSC8/鼠标捕获；右键目标与复制状态准确；空选区不覆盖剪贴板。
	▪	恢复输入需区分清终端键盘模式与向前台任务发送控制字符。HerdrX当前repair会写Ctrl-C和stty sane，不能把它描述为无副作用；实现等价修复时显式说明，优先恢复客户端模式，强制中断操作另有明确入口。
	▪	文件/图片投递根据Agent能力决定粘贴、引用路径或远端暂存；未知能力不能报成功，失败不丢原数据。
同版本libghostty不意味着相同宿主行为。HerdrX已有的IME范围、隐藏尺寸和PTY代次保护继续保留，针对上述事件测试后再补差异。
