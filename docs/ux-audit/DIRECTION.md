# Workbench refinement

Mode: Operate. Existing native terminal workbench; preserve identity and user appearance/font preferences. The audit SPEC plus SCOPE.md govern this iteration.

## Direction contract

THESIS: A quiet terminal workbench where the task name and the intended device remain clear. Dedicated Agent launching and all file interfaces leave the surface.

OWN-WORLD: Preserve native SwiftUI/AppKit controls, semantic system text, theme-aware Ghostty content, and the purple slash app identity. Neutral chrome recedes; selection, focus and execution states retain distinct accents.

STORY: Find a task, see its state and device, open its terminal, then continue work without focus moving unexpectedly. Creation and destructive actions identify their original objects.

FIRST VIEWPORT: One 28-point integrated tab strip; a 260-point sidebar with 40-point action and filter rows; task-first Agent rows; terminal panes fill the remainder. The sidebar primary action creates a Space, while the tab plus creates a terminal tab.

FORM: Preserve the specified compact native layout. The user's measured wireframe determines form; no concept seed or alternative visual world applies.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
