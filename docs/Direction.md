# Native workbench direction

The user's confirmed direction is a native macOS workbench: device/space sidebar, central tabs and full-fidelity terminals, no built-in file browser or preview. Code first, run and inspect the actual app. The visual assignment is bounded by that explicit native choice.

The first viewport is a working shell. The interface uses macOS system type, semantic colors and standard settings controls. Terminal content owns most of the window; only the selected space and pane receive the accent. Status must distinguish device connection from terminal attachment and agent execution. Hidden surfaces retain their dimensions and suspend drawing.

The signature interaction is retaining native terminal surfaces while switching tabs, rather than reattaching processes. The icon is a recognizable ivory H-shaped herd animal on charcoal. Plugin actions, logs and panels inherit the same native language, using the official Herdr API.

The user explicitly removed native directory browsing and previews. Toolbar controls and shortcuts for that feature are absent.

Risk: compact tab labels and long remote names must truncate without covering controls. Verify main window, split shell, Jump and settings at the actual desktop size. This is a native application; no web detector applies.
